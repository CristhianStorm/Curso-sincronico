# Sistema de tutorías online

Aplicación educativa para organizar la interacción entre estudiantes y docentes, desde el acceso de usuarios hasta el seguimiento de las sesiones.

## Funcionalidades presentes en el código

- Autenticación con JWT y gestión de roles.
- Consultas y foros.
- Archivos adjuntos.
- Informes de sesiones.
- Integración para videollamadas.

## Tecnologías

Java 17, Spring Boot, Spring Security, Spring Data JPA, Oracle y Maven.

## Explorar el proyecto

| Ruta | Contenido |
| --- | --- |
| `pom.xml` | Dependencias y configuración de Maven. |
| `src/main/java/com/gestion/emprendedora/config` | Configuración de seguridad y JWT. |
| `src/main/java/com/gestion/emprendedora/controllers` | Controladores de la aplicación. |
| `src/main/java/com/gestion/emprendedora/entities` | Entidades del dominio. |
| `src/main/resources` | Recursos y configuración. |

El proyecto incluye Maven Wrapper. Para trabajar con él, usá JDK 17 y revisá primero la configuración de la base de datos y los servicios externos del entorno.
